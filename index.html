# Lancer Quizzo en local
git clone https://example.com/quizzo.git
cd quizzo
docker compose up -d
# Front : http://localhost:3000
# API   : http://localhost:1337
  • Front-end Next.js
  • API Strapi et base PostgreSQL
  • Conteneurs Docker et Compose
  • Pipeline CI/CD à chaque commit
